# Fusion Reactor Control Systems

An interactive, static web page: pick a fusion machine and see its main parts mapped to how each one is controlled: which loops run, how fast, how they are tested and monitored. The tokamak is the first machine; stellarator and magnetic mirror are coming later. It is a simplified, TCV-inspired illustration for learning, not an official representation of TCV, EPFL or Fusionality. Plain HTML, CSS and vanilla JavaScript: no framework, no build step.

**Live:** https://dcarvalh.github.io/FusionReactorControlSystems/

## Run locally

```sh
python3 -m http.server
```

Then open http://localhost:8000.
